e:T21c4,<h2>Echover</h2><p>A small, custom-rendered audiobook player for the desktop, written in Rust on top of <strong>Vulkan via <code>ash</code></strong>, <strong><code>winit</code></strong>, <strong><code>fontdue</code></strong>, <strong><code>tiny-skia</code></strong>, and <strong><code>rodio</code></strong>, backed by <strong><code>rusqlite</code></strong> for the library and playback state.</p><p>The UI is hand-drawn — every panel, button and icon is a quad submitted to a single graphics pipeline that branches in the fragment shader between an SDF rounded-rect and a sampled glyph. There&#39;s no widget toolkit; the whole interface fits in a couple hundred lines of layout code per page.</p><h3>Quick start</h3><pre><code>cargo run            # debug build + launch
cargo run --release  # release build, smoother frame pacing

cargo test           # unit + integration tests
cargo clippy --all-targets
cargo fmt</code></pre><p>By default Echover scans <code>./library/</code> (gitignored) for audiobooks on first launch.
