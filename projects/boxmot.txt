For methods leveraging appearance-based tracking, we offer both heavyweight  (<a href="https://arxiv.org/pdf/2211.13977.pdf" target="_blank" rel="noopener noreferrer">CLIPReID</a>) and lightweight (<a href="https://arxiv.org/pdf/2101.10774.pdf" target="_blank" rel="noopener noreferrer">LightMBN</a>, <a href="https://arxiv.org/pdf/1905.00953.pdf" target="_blank" rel="noopener noreferrer">OSNet</a>) state-of-the-art ReID models, available via automatic download. Additionally, clear and practical examples demonstrate how to effectively integrate these trackers with various popular models, enabling versatility across diverse vision tasks.</p><p>&lt;div align=&quot;center&quot;&gt;</p><p>&lt;!-- START TRACKER TABLE --&gt; | Tracker | Status  | HOTA↑ | MOTA↑ | IDF1↑ | FPS | | :-----: | :-----: | :---: | :---: | :---: | :---: | | <a href="https://arxiv.org/abs/2408.13003" target="_blank" rel="noopener noreferrer">boosttrack</a> | ✅ | 68.649 | 76.042 | 81.923 | 25 | | <a href="https://arxiv.org/abs/2206.14651" target="_blank" rel="noopener noreferrer">botsort</a> | ✅ | 68.251 | 78.328 | 80.622 | 46 | | <a href="https://arxiv.org/abs/2110.06864" target="_blank" rel="noopener noreferrer">bytetrack</a> | ✅ | 67.619 | 78.081 | 79.188 | 1265 | | <a href="https://arxiv.org/abs/2202.13514" target="_blank" rel="noopener noreferrer">strongsort</a> | ✅ | 67.394 | 76.413 | 79.017 | 17 | | <a href="https://arxiv.org/abs/2302.11813" target="_blank" rel="noopener noreferrer">deepocsort</a> | ✅ | 67.348 | 75.832 | 79.584 | 12 | | <a href="https://arxiv.org/abs/2203.14360" target="_blank" rel="noopener noreferrer">ocsort</a> | ✅ | 66.441 | 74.546 | 77.892 | 1483 | | <a href="https://openaccess.thecvf.com/content/CVPR2023W/E2EAD/papers/Stadler_An_Improved_Association_Pipeline_for_Multi-Person_Tracking_CVPRW_2023_paper.pdf" target="_blank" rel="noopener noreferrer">imprassoc</a> | ✅ | 63.699 | 76.407 | 70.837 | 26 |</p><p>&lt;!-- END TRACKER TABLE --&gt;</p><p>&lt;sub&gt; NOTES: Evaluation was conducted on the second half of the MOT17 training set, as the validation set is not publicly available and the ablation detector was trained on the first half. We employed <a href="https://github.com/mikel-brostrom/boxmot/releases/download/v11.0.9/runs2.zip" target="_blank" rel="noopener noreferrer">pre-generated detections and embeddings</a>. Each tracker was configured using the default parameters from their official repositories. &lt;/sub&gt;</p><p>&lt;/div&gt;</p><p>&lt;/details&gt;</p><h3>Why BOXMOT?</h3><p>Multi-object tracking solutions today depend heavily on the computational capabilities of the underlying hardware. BoxMOT offers a wide range of tracking methods designed to accommodate various hardware constraints—from CPU-only setups to high-end GPUs. Additionally, we provide scripts for rapid experimentation that allow you to save detections and embeddings once, and then load them into any tracking algorithm, eliminating the need to repeatedly generate this data.</p><h3>Installation</h3><p>Start with <a href="https://www.python.org/" target="_blank" rel="noopener noreferrer"><strong>Python&gt;=3.9</strong></a> environment.</p><p>If you want to run the YOLOX, YOLOv10 or YOLOv11 examples:</p><pre><code>git clone https://github.com/mikel-brostrom/boxmot.git
cd boxmot
pip install poetry
poetry install --with yolo  # installed boxmot + yolo dependencies
poetry shell  # activates the newly created environment with the installed dependencies</code></pre><p>but if you only want to import the tracking modules you can simply:</p><pre><code>pip install boxmot</code></pre><h3>YOLOv8 | YOLOv9 | YOLOv10 examples</h3><p>&lt;details&gt; &lt;summary&gt;Tracking&lt;/summary&gt;</p><pre><code>$ python tracking/track.py --yolo-model yolov10n      # bboxes only
  python tracking/track.py --yolo-model yolov9s       # bboxes only
  python tracking/track.py --yolo-model yolov8n       # bboxes only
                                        yolov8n-seg   # bboxes + segmentation masks
                                        yolov8n-pose  # bboxes + pose estimation
</code></pre><p>  &lt;/details&gt;</p><p>&lt;details&gt; &lt;summary&gt;Tracking methods&lt;/summary&gt;</p><pre><code>$ python tracking/track.py --tracking-method deepocsort
                                             strongsort
                                             ocsort
                                             bytetrack
                                             botsort
                                             imprassoc
                                             boosttrack</code></pre><p>&lt;/details&gt;</p><p>&lt;details&gt; &lt;summary&gt;Tracking sources&lt;/summary&gt;</p><p>Tracking can be run on most video formats</p><pre><code>$ python tracking/track.py --source 0                               # webcam
                                    img.jpg                         # image
                                    vid.mp4                         # video
                                    path/                           # directory
                                    path/*.jpg                      # glob
                                    &#39;https://youtu.be/Zgi9g1ksQHc&#39;  # YouTube
                                    &#39;rtsp://example.com/media.mp4&#39;  # RTSP, RTMP, HTTP stream</code></pre><p>&lt;/details&gt;</p><p>&lt;details&gt; &lt;summary&gt;Select ReID model&lt;/summary&gt;</p><p>Some tracking methods combine appearance description and motion in the process of tracking. For those which use appearance, you can choose a ReID model based on your needs from this <a href="https://kaiyangzhou.github.io/deep-person-reid/MODEL_ZOO" target="_blank" rel="noopener noreferrer">ReID model zoo</a>. These model can be further optimized for you needs by the <a href="https://github.com/mikel-brostrom/yolo_tracking/blob/master/boxmot/appearance/reid_export.py" target="_blank" rel="noopener noreferrer">reid_export.py</a> script</p><pre><code>$ python tracking/track.py --source 0 --reid-model lmbn_n_cuhk03_d.pt               # lightweight
                                                   osnet_x0_25_market1501.pt
                                                   mobilenetv2_x1_4_msmt17.engine
                                                   resnet50_msmt17.onnx
                                                   osnet_x1_0_msmt17.pt
                                                   clip_market1501.pt               # heavy
                                                   clip_vehicleid.pt
                                                   ...</code></pre><p>&lt;/details&gt;</p><p>&lt;details&gt; &lt;summary&gt;Filter tracked classes&lt;/summary&gt;</p><p>By default the tracker tracks all MS COCO classes.</p><p>If you want to track a subset of the classes that you model predicts, add their corresponding index after the classes flag,</p><pre><code>python tracking/track.py --source 0 --yolo-model yolov8s.pt --classes 16 17  # COCO yolov8 model. Track cats and dogs, only</code></pre><p><a href="https://tech.amikelive.com/node-718/what-object-categories-labels-are-in-coco-dataset/" target="_blank" rel="noopener noreferrer">Here</a> is a list of all the possible objects that a Yolov8 model trained on MS COCO can detect. Notice that the indexing for the classes in this repo starts at zero</p><p>&lt;/details&gt;</p><p>&lt;/details&gt;</p><p>&lt;details&gt; &lt;summary&gt;Evaluation&lt;/summary&gt;</p><p>Evaluate a combination of detector, tracking method and ReID model on standard MOT dataset or you custom one by</p><pre><code>$ python3 tracking/val.py --yolo-model yolov8n.pt --reid-model osnet_x0_25_msmt17.pt --tracking-method deepocsort --verbose --source ./assets/MOT17-mini/train
$ python3 tracking/val.py --yolo-model yolov8n.pt --reid-model osnet_x0_25_msmt17.pt --tracking-method ocsort     --verbose --source ./tracking/val_utils/MOT17/train</code></pre><p>Detections and embeddings are stored for the selected YOLO and ReID model respectively, which then be loaded into any tracking algorithm. Avoiding the overhead of repeatedly generating this data. &lt;/details&gt;</p><p>&lt;details&gt; &lt;summary&gt;Evolution&lt;/summary&gt;</p><p>We use a fast and elitist multiobjective genetic algorithm for tracker hyperparameter tuning. By default the objectives are: HOTA, MOTA, IDF1. Run it by</p><pre><code># saves dets and embs under ./runs/dets_n_embs separately for each selected yolo and reid model
$ python tracking/generate_dets_n_embs.py --source ./assets/MOT17-mini/train --yolo-model yolov8n.pt yolov8s.pt --reid-model weights/osnet_x0_25_msmt17.pt
# evolve parameters for specified tracking method using the selected detections and embeddings generated in the previous step
$ python tracking/evolve.py --dets yolov8n --embs osnet_x0_25_msmt17 --n-trials 9 --tracking-method botsort --source ./assets/MOT17-mini/train</code></pre><p>The set of hyperparameters leading to the best HOTA result are written to the tracker&#39;s config file.</p><p>&lt;/details&gt;</p><p>&lt;details&gt; &lt;summary&gt;Export&lt;/summary&gt;</p><p>We support ReID model export to ONNX, OpenVINO, TorchScript and TensorRT</p><pre><code># export to ONNX
$ python3 boxmot/appearance/reid_export.py --include onnx --device cpu
# export to OpenVINO
$ python3 boxmot/appearance/reid_export.py --include openvino --device cpu
# export to TensorRT with dynamic input
$ python3 boxmot/appearance/reid_export.py --include engine --device 0 --dynamic</code></pre><p>&lt;/details&gt;</p><h3>Custom tracking examples</h3><p>&lt;div align=&quot;center&quot;&gt;</p><p>| Example Description | Notebook | |---------------------|----------| | Torchvision bounding box tracking with BoxMOT | <a href="https://img.shields.io/badge/Notebook-torchvision_det_boxmot.ipynb-blue" target="_blank" rel="noopener noreferrer">![Notebook</a>](examples/det/torchvision_boxmot.ipynb) | | Torchvision pose tracking with BoxMOT | <a href="https://img.shields.io/badge/Notebook-torchvision_pose_boxmot.ipynb-blue" target="_blank" rel="noopener noreferrer">![Notebook</a>](examples/pose/torchvision_boxmot.ipynb) | | Torchvision segmentation tracking with BoxMOT | <a href="https://img.shields.io/badge/Notebook-torchvision_seg_boxmot.ipynb-blue" target="_blank" rel="noopener noreferrer">![Notebook</a>](examples/seg/torchvision_boxmot.ipynb) |</p><p>&lt;/div&gt;</p><h3>Contributors</h3><p>&lt;a href=&quot;https://github.com/mikel-brostrom/yolo_tracking/graphs/contributors &quot;&gt;   &lt;img src=&quot;https://contrib.rocks/image?repo=mikel-brostrom/yolo_tracking&quot; /&gt; &lt;/a&gt;</p><h3>Contact</h3><p>For BoxMOT bugs and feature requests please visit <a href="https://github.com/mikel-brostrom/boxmot/issues" target="_blank" rel="noopener noreferrer">GitHub Issues</a>.
