e:T2cb6,<h2>ViLa-MIL</h2><p><strong>Dual-scale Vision-Language Multiple Instance Learning for Whole Slide Image Classification</strong>, <em>CVPR 2024</em>.</p><p>Jiangbo Shi, Chen Li, Tieliang Gong, Yefeng Zheng, Huazhu Fu</p><p>[[Open Access Version]](https://openaccess.thecvf.com/content/CVPR2024/papers/Shi_ViLa-MIL_Dual-scale_Vision-Language_Multiple_Instance_Learning_for_Whole_Slide_Image_CVPR_2024_paper.pdf) | <a href="https://github.com/Jiangbo-Shi/ViLa-MIL?tab=readme-ov-file#citation" target="_blank" rel="noopener noreferrer">[Cite</a>]</p><p><strong>Abstract</strong>: Multiple instance learning (MIL)-based framework has become the mainstream for processing the whole slide image (WSI) with giga-pixel size and hierarchical image context in digital pathology. However, these methods heavily depend on a substantial number of bag-level labels and solely learn from the original slides, which are easily affected by variations in data distribution. Recently, vision language model (VLM)-based methods introduced the language prior by pre-training on large-scale pathological image-text pairs. However, the previous text prompt lacks the consideration of pathological prior knowledge, therefore does not substantially boost the model&#39;s performance. Moreover, the collection of such pairs and the pre-training process are very time-consuming and source-intensive. To solve the above problems, we propose a dual-scale vision-language multiple instance learning (<strong>ViLa-MIL</strong>) framework for whole slide image classification. Specifically, we propose a dual-scale visual descriptive text prompt based on the frozen large language model (LLM) to boost the performance of VLM effectively. To transfer the VLM to process WSI efficiently, for the image branch, we propose a prototype-guided patch decoder to aggregate the patch features progressively by grouping similar patches into the same prototype; for the text branch, we introduce a context-guided text decoder to enhance the text features by incorporating the multi-granular image contexts. Extensive studies on three multi-cancer and multi-center subtyping datasets demonstrate the superiority of ViLa-MIL.</p><p>![](image/readme/framework.png)</p><h3>1. Pre-requisites</h3><p>Python (3.7.7), h5py (2.10.0), matplotlib (3.1.1), numpy (1.18.1), opencv-python (4.1.1), openslide-python (1.1.1), openslide (3.4.1), pandas (1.1.3), pillow (7.0.0), PyTorch (1.6.0), scikit-learn (0.22.1), scipy (1.4.1), tensorboardx (1.9), torchvision (0.7.0), captum (0.2.0), shap (0.35.0), clip (1.0).</p><h3>2. Download Dataset</h3><p>The two public TCGA-RCC and TCGA-Lung datasets can be downloaded in <a href="https://portal.gdc.cancer.gov/" target="_blank" rel="noopener noreferrer">NIH Genomic Data Commons Data Portal</a>. For the specific downloading tool, please refer to <a href="https://docs.gdc.cancer.gov/Data_Transfer_Tool/Users_Guide/Data_Download_and_Upload/" target="_blank" rel="noopener noreferrer">GDC Data Transfer.</a></p><h3>3. Prepare Dataset File</h3><p>For each dataset, a <code>.csv</code> file is needed in the following format and put it into the <code>dataset_csv</code> folder:</p><pre><code>Headname: &#39;case_id, slide_id, label&#39;
Each line: &#39;patient_0, TCGA-UZ-A9PS-01Z-00-DX1.3CAF5087-CDAB-42B5-BE7C-3D5643AEAA6D, CCRCC&#39;</code></pre><h3>4. Preprocess Data</h3><p>4.1 Generate Patch Coordinate</p><p>Utilize the sliding window method to generate the patch coordinates from WSI for cropping.</p><pre><code>python create_patches_fp.py \
--source SOURCE_FOLDER \
--slide_name_file SLIDE_NAME_FILE \
--preset tcga.csv \
--save_dir SAVE_FOLDER \
--patch_size 1024 \
--step_size 1024 \
--seg \
--patch \
--uuid_name_file UUID_NAME_FILE</code></pre><p>The list of parameters is as follows:</p><ul><li><code>source</code>: The downloading original WSI folder path in <code>step 2</code>.</li><li><code>slide_name_file</code>: The path of csv dataset file in <code>step 3</code>.</li><li><code>save_dir</code>: The saving folder path for generating results.</li><li><code>uuid_name_file</code>: A file stores the corresponding relations between uuid and slide name in the followling format (&#39;uuid&#39;, &#39;slide name&#39;, &#39;slide label&#39;).</li></ul><p>4.2 Crop Patches</p><p>Utilize the above generated patch coordinate file to crop the patches.</p><pre><code>cd feature_extraction
python patch_generation.py</code></pre><p>Note: the pathes between <code>line 12 and 17</code> are needed to define in <code>patch_generation.py</code>.</p><p>Paramters Descriptions:</p><ul><li><code>slide_folder</code>: The downloading original WSI folder path in <code>step 2</code>.</li><li><code>all_data</code>: The same path as the <code>uuid_name_file</code> in <code>step 4.1</code>.</li><li><code>root_folder</code>: The same path as the save_dir in <code>step 4.1</code>.</li><li><code>define_path_size</code>: For the TCGA dataset, all the patches are cropped at the highest magnification. If patches are needed to crop at 10x with size 256. this parameter should defined as 1024.</li><li><code>save_folder</code>: The path where the cropping patches are saved.</li></ul><p>4.3 Extract Patch Features</p><p>Utilize a pretrain encoder (<em>e.g.,</em> CLIP-pretrained ResNet50) to extract the patch features.</p><pre><code>python patch_extraction.py \
--patches_path &#39;PATCHES_PATH&#39; \
--library_path &#39;LIBRARY_PATH&#39; \
--model_name &#39;clip_RN50&#39; \
--batch_size 64 \</code></pre><p>Parameter Descriptions:</p><ul><li><code>patches_path</code>: The same as the save_folder in <code>step 4.2</code>.</li><li><code>libiary_path</code>: The path where the generated patch features are saved.</li><li><code>model_name</code>: <code>&#39;clip_RN50&#39;</code>  means using CLIP ResNet50 to extract patch features. <code>&#39;resnet50_trunc&#39;</code> means using <code>ResNet50</code> pretrained on ImageNet to extrach features.</li></ul><h3>5. Split Datasets</h3><p>5.1 Generate <code>k</code> splitting datasets with different seeds.</p><pre><code>python create_splits_seq.py \
--label_frac 1 \
--k 5 \
--task &#39;TASK&#39; \
--val_frac VAL_FRAC \
--test_frac TEST_FRAC \
--dataset DATASET \</code></pre><p>Parameter Descriptions:</p><ul><li><code>task</code>: &#39;<code>task_tcga_rcc_subtyping</code>&#39; for the TCGA_RCC dataset.</li><li><code>val_frac</code>: The proportion of the validation set (<em>e.g.</em>, 0.3).</li><li><code>test_frac</code>: The proportion of the test set (<em>e.g.,</em> 0.3).</li><li><code>dataset</code>: Dataset name (<em>e.g.,</em> TCGA_RCC).</li></ul><p>5.2 Build the few-shot dataset split.</p><pre><code>python create_splits_fewshot.py</code></pre><p>Note: the parameters are needed to define between the <code>line 5 and 8</code> in the <code>create_splits_fewshot.py</code>.</p><p>Parameter Descriptions:</p><ul><li><code>N</code>: The case number in training set for each category.</li><li><code>data_foler</code>: The path generated in <code>step 5.1</code>.</li><li><code>all_data</code>: The same path as <code>uuid_name_file</code> in <code>step 4.1</code>.</li><li><code>save_folder</code>: The saved split file path.</li></ul><h3>6. Prepare Text Prompt</h3><p>By querying the frozen LLM (<em>e.g.,</em> GPT-3.5) with the following question, the text prompt will be generated automatically.</p><p><code>Q: What are the visually descriptive characteristics of {class name} at low and high resolution in the whole slide image?</code></p><p>The specific text prompt files for TCGA-RCC and TCGA-Lung datasets are stored in the folder <code>text_prompt</code> using GPT-3.5.</p><h3>7. Training Model</h3><p>Run the following script, and ViLa-MIL will be trained.</p><pre><code>export CUDA_VISIBLE_DEVICES=0
python main.py \
--seed 1 \
--drop_out \
--early_stopping \
--lr 1e-4 \
--k 5 \
--label_frac 1 \
--bag_loss ce \
--task &#39;TASK&#39; \
--results_dir &#39;RESULT_DIR&#39; \
--exp_code &#39;EXP_CODE&#39; \
--model_type ViLa_MIL \
--mode transformer \
--log_data \
--data_root_dir &#39;DATA_ROOT_DIR&#39; \
--data_folder_s &#39;DATA_FOLDER_S&#39; \
--data_folder_l &#39;DATA_FOLDER_L&#39; \
--split_dir &#39;SPLIT_DIR&#39; \
--text_prompt_path &#39;TEXT_PROMPT_PATH&#39; \
--prototype_number 16 \ </code></pre><p>Parameter Descriptions:</p><ul><li><code>task</code>: &#39;<code>task_tcga_rcc_subtyping</code>&#39; for the TCGA_RCC dataset.</li><li><code>results_dir</code>: The path where model training results are saved.</li><li><code>exp_code</code>: The folder saved in <code>results_dir</code>.</li><li><code>data_root_dir</code>: The path where patch features are saved.</li><li><code>data_folder_s</code>: The folder name for low-scale patch features.</li><li><code>data_folder_l</code>: The folder name for high-scale patch features.</li><li><code>split_dir</code>: The same path as <code>save_folder</code> in <code>step 5.2</code>.</li><li><code>text_prompt_path</code>: The path of text prompt file.</li></ul><h3>8. Eval Model</h3><p>Eval the trained model using the following script.</p><pre><code>export CUDA_VISIBLE_DEVICES=0
python eval.py \
--drop_out \
--k 5 \
--k_start 0 \
--k_end 5 \
--task &#39;TASK&#39; \
--results_dir &#39;RESULTS_DIR&#39; \
--models_exp_code &#39;MODELS_EXP_CODE&#39; \
--save_exp_code &#39;SAVE_EXP_CODE&#39; \
--model_type ViLa_MIL \
--mode transformer \
--splits_dir &#39;SPLITS_DIR&#39; \
--data_root_dir &#39;DATA_ROOT_DIR&#39; \
--data_folder_s &#39;DATA_FOLDER_S&#39; \
--data_folder_l &#39;DATA_FOLDER_L&#39; \
--text_prompt_path &#39;TEXT_PROMPT_PATH&#39; \
--prototype_number 16 \ </code></pre><p>Parameter Descriptions:</p><ul><li><code>task</code>: &#39;<code>task_tcga_rcc_subtyping</code>&#39; for TCGA_RCC dataset.</li><li><code>results_dir</code>: The path where model training results are saved.</li><li><code>models_exp_code</code>: The training model saving path.</li><li><code>save_exp_code</code>: The path of saving the evaluation results.</li><li><code>split_dir</code>: The same path as <code>save_folder</code> in <code>step 5.2</code>.</li><li><code>data_root_dir</code>: The path where patch features are saved.</li><li><code>data_folder_s</code>: The folder name for low-scale patch features.</li><li><code>data_folder_l</code>: The folder name for high-scale patch features.</li><li><code>text_prompt_path</code>: The path of the text prompt file.</li></ul><p><code>Note that</code> the symboles $N_l$ and $N$ in Eqs. (6) and (7) of the main manuscript should be revised into $N_p$.</p><h3>Citation</h3><p>If you find our work useful in your research, please consider citing our paper at:</p><pre><code>@inproceedings{shi2024vila,
