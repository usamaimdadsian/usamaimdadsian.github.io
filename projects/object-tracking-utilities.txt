e:Tc3b,<p>&lt;h3 align=&quot;center&quot;&gt;Object Tracking Utilities&lt;/h3&gt;</p><p>&lt;p align=&quot;center&quot;&gt;Repository provide code to check the accuracy of a tracking algorithm.     &lt;br&gt; &lt;/p&gt;</p><h3>📝 Table of Contents</h3><ul><li>[📝 Table of Contents](#-table-of-contents)</li><li>[🧐 About ](#-about-)</li><li>[🏁 Getting Started ](#-getting-started-)</li><li>[🎈 Usage ](#-usage-)</li><li>[🎉 Results](#-results)</li><li>[✍️ Authors ](#️-authors-)</li></ul><h3>🧐 About &lt;a name = &quot;about&quot;&gt;&lt;/a&gt;</h3><p>The code in this repository estimates the accuracy of real time tracking algorithm using polynomial fitting. The code fits the polynomial on the real time tracking data and calculates how near the tracking positions are on this polynomial. Closer tracking positions to the polynomial mean the tracking is more accurate.</p><h3>🏁 Getting Started &lt;a name = &quot;getting_started&quot;&gt;&lt;/a&gt;</h3><p>To run this code numpy, scikit-learn and matplotlib should be installed. To install these run the following commands on your terminal.</p><pre><code>pip install -r requirements.txt</code></pre><h3>🎈 Usage &lt;a name=&quot;usage&quot;&gt;&lt;/a&gt;</h3><p>To use the code you should have the rectangle coordinates of the tracking positions. Rectangle coordinates should be in this form <strong>x1,y1,w,h</strong>, where (x1,y1) is the position of top left corner of the rectangle and w,h represent widht and height respectively.</p><ol><li>Import the TrackingEvaluator Class</li></ol><pre><code>from utils.tracking_evaluator import TrackingEvaluator</code></pre><ol><li>Defination</li></ol><pre><code>&quot;&quot;&quot;
:param fitter_type: ransac, ransac_polynomial, ransac_gaussian, polynomial 
:param poly_degree: degree of the polynomial
:param data: numpy array with four columns x1,y1,w,h here x1,y1 represent top left corner w and h represent width and height
:param tracking_pos: top_left, top_right, bottom_left, bottom_right, center
&quot;&quot;&quot;

evaluator = TrackingEvaluator(data,fitter_type=&quot;ransac_polynomial&quot;,tracking_pos=&quot;center&quot;)
</code></pre><ol><li>Training and Prediction</li></ol><pre><code>evaluator.fit()
evaluator.predict()</code></pre><ol><li>Visualize the Fitting</li></ol><pre><code>evaluator.visualize()</code></pre><ol><li>Check the error value</li></ol><pre><code>&quot;&quot;&quot;:param err_type: mse, mae, custom&quot;&quot;&quot;
print(evaluator.calc_error(&quot;mse&quot;))</code></pre><p>Look at test.ipynb for to check the implementation.</p><h3>🎉 Results</h3><p>Following code gives this type of result</p><pre><code>evaluator = TrackingEvaluator(data)
