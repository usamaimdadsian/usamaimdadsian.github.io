ML4W OS - Dotfiles for Hyprland

An Ansible-managed Hyprland setup based on ML4W dotfiles, with optional Nix/Home Manager integration and a personal dotfiles overlay.

<img width="2560" height="1440" alt="image" src="https://ml4w.com/os/dotfiles2110.jpg" />

What This Repo Does

  • Applies ML4W desktop dotfiles as the base layer.
  • Installs Arch packages (including AUR packages via paru).
  • Optionally installs and applies Nix + Home Manager.
  • Applies personal non-desktop dotfiles from git@github.com:usamaimdadsian/dotfiles.git using stow --adopt.

Quick Start (Ansible First)

  1. Install prerequisites:
sudo pacman -S --needed ansible git make
  1. Install Ansible collections:
make bootstrap
  1. Review and edit configuration:
  • ansible/group_vars/all.yml
  1. Dry run:
make check
  1. Apply:
make apply

Key Configuration Variables

  • ml4w_enable_nix
  • ml4w_enable_home_manager
  • ml4w_enable_aur
  • ml4w_personal_dotfiles_enabled
  • ml4w_personal_dotfiles_repo
  • ml4w_personal_dotfiles_stow_paths
  • ml4w_desktop_protected_paths

Protected ML4W desktop paths are not allowed in the personal overlay:

  • .config/hypr
  • .config/waybar
  • .config/wlogout
  • .config/swaync
  • .config/ml4w
  • .config/waypaper

Default personal overlay paths:

  • .bashrc, .zshrc, .tmux.conf
  • .config/alacritty, .config/ghostty, .config/mpv
  • .config/systemd, .config/nvim
